# NovaEngine

A graphics engine proposed for Honor's Precalculus Project. 2021, High Tech High North County.

# Requirements

* CMake 3.16 or newer
* SDL2
* OpenGL (and a GPU that supports it)

# Installation

1. Open your terminal and clone the repository:

```bash
git clone https://github.com/QuasariumGH/NovaEngine.git
```

2. Enter the project directory:

```bash
cd NovaEngine
```

3. Create the build directory:

```bash
cmake -S . -B build
```

# How to Run

1. Build NovaEngine:

```bash
cmake --build build
```

2. Run the generated executable.

### Linux / macOS

```bash
./build/NovaEngine
```

### Windows

Find and run `NovaEngine.exe` from the generated build directory.
